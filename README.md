# NordTek Solutions AS sin kunnskapsbase for kunder
En nettside for NordTek Solution AS sine kunder som søker etter råd der de kan finne artikler, guider og resurser for effektiv problemløsning.

# Funksjoner
- En atikkel side der anstatte av NordTek Solutions kan legge til guider for brukere for å motstå tid for de på teknisk support og telefon.
- En lovverks side der brukere kan se igjennom alle lovverk relevant til NordTek Solutions AS slik at de er oppmerksom på deres rettigheter og krav for å sammarbeide med NordTek Solutions.
- En kundesupport side for brukere med en oversikt på alle NordTek Soultions support kanaler, med åpningstider og tilgjengelighet.

# Kjør NordTek Solutions AS Kunnskapsbase lokalt på din maskin
1. Installer Docker Desktop
2. Åpne repositoriet i GitHub desktop og klon den.
3. Kjør denne i terminalen: `docker compose up`
